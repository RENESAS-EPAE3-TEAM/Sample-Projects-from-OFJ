# LIN_slave_sample 工程说明

## 1. 工程概述

本工程为基于 RL78/F24 RLIN3 外设的 LIN 2.1 从机参考例程，用于演示从机节点初始化、信号读写、帧发布与订阅、通信标志检测，以及与 LIN 主机的基本通信。

## 2. 软件运行环境

| 软件/组件 | 版本或要求 |
| --- | --- |
| 运行环境 | Renesas CS+ for CC-RL，Package V8.14.00 / ProductVersion 9.14.00.00 |
| 编译器 | Renesas CC-RL V1.15.01 |
| BSP | RL78 BSP v1.90 |
| Smart Configurator | Smart Configurator for RL78 |
| 调试器 | Renesas E2 / E2 Lite |

## 3. 支持的开发板 / MCU

- MCU：RL78/F24。
- 型号：R7F124FPJ5xFB。
- 适用于 TB-RL78F24 或自定义 RL78/F24 板。

## 4. 硬件要求

- RL78/F24 目标板及 LIN 收发器；
- LIN 主机或分析仪；
- USB 线缆及与所选调试器、目标板匹配的 RL78 调试连接线。

## 5. 硬件连接

### 5.1 调试器连接

使用板载调试器或外接 E2 / E2 Lite 进行连接，具体方式以目标板及调试器说明为准。

### 5.2 LIN 连接

本工程默认使用 RLIN3 Channel0，工程配置中对应引脚为 P13/P14：

| 目标板引脚 | 连接对象 |
| --- | --- |
| P13/LTXD0 | LIN 收发器 TXD |
| P14/LRXD0 | LIN 收发器 RXD |
| P5.3 | LIN 收发器使能 / 唤醒控制端，需确认与样例高电平控制方式匹配 |

将收发器 LIN 引脚连接至 LIN 主机或分析仪的 LIN 接口。

### 5.3 电源连接

按硬件要求为目标板和 LIN 收发器供电，目标板、收发器及 LIN 主机或分析仪共地。

> **注意：** 修改接线前应断电。

### 5.4 波形观察

将示波器或逻辑分析仪连接至 P10.1～P10.4，观察通信事件翻转；观察 LIN 总线波形时，使用量程匹配的示波器探头。

## 6. 配置原理与说明

本工程通过 LIN 2.1 从机驱动完成初始化和帧收发。主机发送帧头后，从机根据配置发送或接收响应数据；应用程序通过信号接口读写数据，并根据通信标志翻转调试端口。

### 6.1 基本配置

| 项目 | 配置 |
| --- | --- |
| LIN 通道 | RLIN3 Channel0 |
| 工作模式 | LIN 2.1 从机模式 |
| 输入时钟 | 40 MHz |
| 唤醒检测方式 | 下降沿检测 |
| 通道使能 | `RLIN3_CFG_USE_LIN_CH0=1` |

### 6.2 帧与信号配置

`conflin_0.c` 默认配置 5 个消息缓冲区：

| 帧名称 | PID | 从机方向 | 数据长度 |
| --- | --- | --- | --- |
| Frame_A | `0x80` | 发布，发送响应 | 1 字节 |
| Frame_B | `0xC1` | 订阅，接收响应 | 1 字节 |
| Frame_C | `0x42` | 发布，发送响应 | 2 字节 |
| Frame_D | `0x03` | 订阅，接收响应 | 8 字节 |
| Frame_Err | `0x6F` | 发布，发送响应 | 1 字节 |

发布和订阅方向均以本从机为参照，帧头由主机发送。

`sample.c` 在主循环中读写 `SIG1`、`SIG3`、`SIG4`～`SIG35` 等信号，并使用以下接口处理通信标志：

- `l_flg_tst()`：检测相关标志；
- `l_flg_clr()`：清除已处理的标志。

修改 LDF 或通信定义时，需同步更新 `conflin_0.h` 和 `conflin_0.c` 中的帧、信号、PID、方向、长度、校验和类型及初始数据。

### 6.3 初始化与通信流程

1. 初始化 LIN 收发器控制引脚和调试端口。
2. 调用 `l_sys_init()`，完成 LIN 系统初始化。
3. 调用 `l_ifc_init(LIN_CHANNEL0)`，完成通道初始化。
4. 主循环读写信号，驱动根据主机帧头完成响应发送或接收。
5. 检测通信标志，翻转对应调试端口，并清除已处理的标志。

## 7. 运行方法

### 7.1 编译与下载

1. 解压 `LIN_slave_sample.zip`，使用 CS+ 打开 `for CS+\LIN_Sample.mtpj`。
2. 编译工程。如需修改或重新生成 LIN 驱动库，参考 `Channel0\readme.txt`，先编译 `liblin21s_CCRL.mtpj`。
3. 使用目标板支持的板载或外接调试器下载并运行程序。

### 7.2 通信测试

配置 LIN 主机或具备主机功能的分析仪，使通信速率、帧标识、数据长度及校验和类型与从机一致，周期执行以下通信：

| 测试帧 | 主机操作 | 从机行为 | 调试端口 |
| --- | --- | --- | --- |
| Frame_A | 发送帧头，读取响应 | 发送 1 字节数据 | P10.1 |
| Frame_B | 发送帧头及 1 字节响应数据 | 接收数据 | P10.2 |
| Frame_C | 发送帧头，读取响应 | 发送 2 字节数据 | P10.3 |
| Frame_D | 发送帧头及 8 字节响应数据 | 接收数据 | P10.4 |

### 7.3 结果检查

- 在 LIN 分析仪中检查响应数据、长度及校验结果；
- 观察 P10.1～P10.4 是否随对应通信事件翻转；
- 在调试器中查看 `u8t_Frm2Data`、`u16t_Frm3Data`、`blt_Frm4Array` 等变量，结合测试数据确认读写结果。

> **注意：** 通信测试时应保持程序连续运行，避免断点暂停影响响应时序。
